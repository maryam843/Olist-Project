# Olist Project

# Brazilian Olist E-Commerce: Seller Trust & Delivery Intelligence

> DSAI 4103 Business Analytics

Brazilian e-commerce platform Olist connects thousands of small sellers to customers 
nationwide. This project builds an end-to-end ML pipeline to predict poor customer 
experiences before they happen — using delivery behavior, seller patterns, and order 
signals to flag at-risk orders early.

**Dataset:** 100,000+ orders | 9 relational CSV files | 2016–2018  
**Source:** [Olist Brazilian E-Commerce — Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)  
**Target:** Predict whether an order will receive a 1–2 star review (binary classification)

Pipeline: EDA → Feature Engineering → AutoML + Ensemble Models → SHAP → Bias Analysis
